# Web & UI Guidelines

- **Optional inputs get an explicit clear (×) button**, last in its row so nothing
  shifts. Don't rely on native "none" states.
- **Enforce model limits at every entry point** — toggles, add buttons, and save.
- **Explain abbreviations** on first use, or with a tooltip when space is tight.
- **Delete lives in the edit form**, unless the form replaces the list while open.
- **Counts derive from the filtered set**, same as the visible list.
- **Accessibility:** WCAG 2.1 AA, 44×44px touch targets, keyboard access, aria labels
  on icon-only controls, confirm destructive actions.
